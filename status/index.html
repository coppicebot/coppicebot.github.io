Status: what is and isn't watched

Coppice has no public uptime history yet. When it does, it will be linked here. Until then, this page says plainly what Coppice watches and what it doesn't. Problems with Coppice itself are posted in the Coppice Support server.

What Coppice watches

  • Each Minecraft server you add, on a repeating schedule: online or not, player count, version, message of the day and ping. Each card says when its status is from.
  • An offline alert needs two failed checks in a row, so one dropped answer doesn't page you.
  • Checks come from one place: a server in New York, USA (DigitalOcean NYC3).

What it doesn't watch

  • Whether players can actually join and play. Coppice asks the same question the multiplayer screen asks. A server can answer that and still be lagging, full or broken in game.
  • Lag inside the game (TPS), plugins, mods or the server's console.
  • Reachability from anywhere but New York. A network problem near your players won't show; one near New York can look like an outage.
  • Realms. A Realm has no public address to check.
  • Your Discord. If Discord is down, cards and alerts wait for it. An alert that can't be sent within an hour is dropped.

How Coppice itself is kept running

  • The bot runs on one server and restarts by itself if it stops.
  • It keeps timing its own checks and raises a flag if they run late.
  • The database is backed up every night and kept 14 days.
  • If something goes wrong that affects your data, we'll say so on coppicebot.com.
