Coppice commands

Type / in Discord and pick Coppice to see these with hints. Everything is under /coppice. Commands marked Manage Server change settings, so only people with that Discord permission see them by default. Replies to setup and settings are only shown to you.

Start

CommandWhat it doesWho
/coppice setup <address>Posts a live status card in this channel and alerts when the server goes offline. Optional: edition, alert_channel, alert_role, nickname.Manage Server
/coppice status <address>Checks any server once. Watches nothing.Anyone
/coppice helpHow Coppice works and how to start.Anyone
/coppice settingsEvery setting here, its current value and the command that changes it.Anyone

Servers and alerts

CommandWhat it doesWho
/coppice listThe servers this Discord watches.Anyone
/coppice remove <server>Stops watching a server and deletes its card and history.Manage Server
/coppice alerts <channel> [role]Where offline and back-online alerts go, and which role is pinged. Leave the role empty for no ping.Manage Server
/coppice nickname [name] [server]A short name for the card and alerts, up to 32 characters. Empty removes it.Manage Server
/coppice default <server>The server commands use when you don't name one.Manage Server
/coppice cardcolor [color]The color of this Discord's status cards: a name like blue or gold, or a hex code. Offline cards stay red. reset:True goes back to green.Manage Server
/coppice quiethours <start> <end> <timezone>Holds alerts overnight and posts one summary when the window ends. Example: 23:00 07:00 America/New_York.Manage Server
/coppice quiethours-offSends alerts right away again.Manage Server

Graphs and patch notes

CommandWhat it doesWho
/coppice graph <server> [period]Players, ping and uptime: last 24 hours, 7 days or 30 days. 90 days with Premium.Anyone
/coppice patchnotes <channel>Posts each new Minecraft Java version there. snapshots:True adds snapshots and pre-releases (Premium).Manage Server
/coppice patchnotes-off [channel]Stops patch notes in one channel, or everywhere if empty.Manage Server
/coppice hostWhat to check before paying for a Minecraft host.Anyone

Premium and referrals

CommandWhat it doesWho
/coppice premiumWhat Premium adds, and this Discord's referral code.Anyone
/coppice redeem <code>Uses another community's referral code. Works within 14 days of adding Coppice. Rules.Manage Server
/coppice alerttext [offline] [online]Premium: your own words on alerts. {server} and {downtime} are filled in. reset:True goes back to the default.Manage Server

Coming from MCStatusBot
